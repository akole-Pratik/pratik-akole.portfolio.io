How do I get a token?
  1. On GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token.
  3. Under Repository access, choose Only select repositories and pick this portfolio repo only.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate, copy the token, and paste it above. It's only ever stored in your own browser, never in the code.
